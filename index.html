มินิเกม: ลากจับคู่หน้าที่กับสัญลักษณ์ผังงาน

คลิกเลือกกล่องหน้าที่ทางซ้าย แล้วคลิกเลือกสัญลักษณ์ที่สัมพันธ์กันทางขวา

จับคู่ถูกต้อง: 0/5
1. Terminal (จุดเริ่มต้น / จุดสิ้นสุด)
2. Process (การประมวลผล / คำนวณ)
3. Decision (ตรวจสอบเงื่อนไข / ตัดสินใจ)
4. Data (Input/Output ข้อมูลทั่วไป)
5. Flowline (ลูกศรแสดงทิศทางการทำงาน)
